# 🎨 Kodachrome LUT Gallery

Galeria interativa para aplicação de LUTs cinematográficas em imagens.

## ✨ Características

- 🎬 289 LUTs de filmes analógicos
- 🖼️ Upload via drag & drop
- ��️ Preview em tempo real
- 📦 Download em ZIP
- 📱 Design responsivo
- ⚡ Netlify Functions

## 🚀 Início Rápido

```bash
npm install
npm start
```

Acesse: `http://localhost:3000`

## 📦 Build e Deploy

```bash
npm run build
```

Deploy no Netlify:
- Build command: `npm run build`
- Publish directory: `dist`

## 🛠️ Stack

- HTML5, CSS3, JavaScript ES6+
- Webpack 5, Babel
- Netlify Functions
- Sharp (processamento de imagens)

## 📁 Estrutura

```
src/              # Frontend
netlify/functions/  # Backend serverless
luts/             # 289 arquivos .cube
dist/             # Build
```

## 🎞️ LUTs Incluídas

289 filtros: Kodak, Fuji, Polaroid, Ilford, Rollei, Lomography
